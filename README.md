# varaprasadh.dev

Personal site. Built with Astro and Tailwind.

```bash
npm install
npm run dev
```

Production build: `npm run build` then `npm run preview`.

`site` in `astro.config.mjs` must stay `https://varaprasadh.dev`. Sitemap, RSS, canonical, and Open Graph URLs all come from that value — do not point it at a Vercel preview host.
